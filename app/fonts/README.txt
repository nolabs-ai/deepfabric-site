Locally bundled Latin WOFF2 fonts, used by next/font/local in app/layout.tsx.
This keeps production builds independent of Google Fonts CSS and downloads.

Sources (Fontsource npm packages, version 5.3.0):
- @fontsource-variable/inter: files/inter-latin-wght-normal.woff2 (100-900)
- @fontsource-variable/sora: files/sora-latin-wght-normal.woff2 (100-800)
- @fontsource/ibm-plex-mono: files/ibm-plex-mono-latin-{200,300,400,500,600}-normal.woff2

All three families are licensed under SIL Open Font License 1.1.
The original license for each family is included alongside the font files.
